# portfolio-dummy

Preview it here 🠮 <https://makalestainton-creator.github.io/portfolio-dummy/>.

This is the completed assignment issued by [The Odin Project](https://www.theodinproject.com/lessons/node-path-advanced-html-and-css-homepage) that required creating a portfolio website using the knowldge gained in the advanced HTML and CSS lessons.

The major struggle I encountered was responsive design trying to figure out the layout pattern of the page on smaller screens. Nevertheless, I was able to come up with the final working version that I consider among the best interfaces I've built so far.

I look forward to making the page more accessible by assistive technologies and people on the internet in general.
